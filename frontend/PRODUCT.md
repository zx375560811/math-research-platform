## Platform

Web；电脑与手机浏览器。服务器为 Linux，通过 GitHub 分发代码。

## Users and jobs

数学学习与研究用户，登录后查找教材、按课程路线学习，并在 PDF/DJVU 阅读器保存个人进度、高亮与笔记。普通用户不能上传或管理底层文献。

## Product

文献库是共享底层，用户先看到应用模块。现有入口是文档库、数学与应用数学、系列书籍。系列书籍包含用户提供的六个系列，AI 可根据学习需求推荐库中实际已有的教材。

## Stack

Java 17 / Spring Boot、SQLite；原生 HTML/CSS/JavaScript，由后端提供静态资源。保持现有 Morphicons 按钮互动、PDF.js 与原生 DJVU 阅读流程。
