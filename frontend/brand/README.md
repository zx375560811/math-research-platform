# 公理标志

设计概念：由一个已知起点出发，推演出不同结构。墨蓝底上的三条几何路径与青色方形起点均为本项目直接绘制；“公理”字标也由 SVG 笔画绘制，不依赖外部字体、素材或第三方 Logo。

- logo-mark.svg：64×64 图形标志，用于网站与小尺寸头像。
- logo.svg：图形与自绘“公理”字标，透明背景。
- logo-monochrome.svg：单色版本。

网站登录、注册、应用侧栏与管理侧栏使用内联 SVG，避免新增静态资源部署依赖。品牌文字使用“公理”，项目技术名称仍为 math-research-platform。
