# 讨论模块

入口：工作台“讨论”、左侧“讨论”，路由 `#/discussions`。全体已登录用户可见，未登录继续使用原有登录与邀请码注册流程。

## 用户功能

- 按数学与应用数学、数学到人工智能、数学竞赛、学习交流筛选，搜索标题与正文，查看最近讨论、等待回复或我发起的话题。
- 发布话题与回复；正文支持现有 Markdown、代码与 KaTeX 公式，发布前可预览。不提供附件上传。
- 从文档库搜索并关联一本教材。点击教材打开原有文档库预览，不改写阅读进度。
- 作者可以编辑或删除自己的内容。删除话题会连同回复删除，页面提供明确的确认步骤。
- 管理员在话题详情页可置顶、关闭或开放回复、删除任意话题和回复；不能冒用作者编辑他人的内容。

帖子每页 9 条，桌面端 3 行 3 列正方形卡片，平板 2 列、手机 1 列；整张卡片可点击或按 Enter 进入正文，列表显示标题、分类、作者与回复数。回复仍每页 20 条，均显示当前页、总页数与条数。编辑采用版本检查，旧页面的保存不会覆盖其他页面的新版本。同账号在当前页面会话内保留未发布草稿，切换账号或登出后清除；草稿不写入浏览器永久存储，刷新页面前请先保存内容。

## 文件与数据

- `backend/src/main/java/org/mathplatform/DiscussionController.java`：讨论接口、权限、版本检查与事务。
- `backend/src/main/resources/schema.sql`：`discussion_topics`、`discussion_replies` 与索引，服务启动时自动增量建表。
- `frontend/discussion.js`、`frontend/discussion.css`：列表、发帖、预览、详情、回复和管理交互，沿用 Axiom 配色及 Morphicons。
- 正式内容保存在当前 SQLite 数据库，与文献库共享用户。关联文献删除时解除关联，保留话题；删除话题不影响文献文件、阅读进度或个人笔记。
- Markdown 经过现有 DOMPurify 清理，数学公式沿用 `richtext.js`，不允许正文执行脚本。所有写入验证登录与 CSRF，服务端分别检查作者与管理员权限。

## 部署

在服务器 SSH 终端执行：

```bash
cd /opt/math-platform && git pull --ff-only && cd backend && ./mvnw -B package && systemctl restart math-platform
```

完成后浏览器 Ctrl + F5。不需要安装 Node.js、不需要新数据库或手工执行建表脚本。备份现有 SQLite 数据库即可包含已发布的讨论。

## 验证

`python3 backend/tests/discussions.py` 使用隔离数据库和真实 Java 服务验证身份权限、置顶与锁定、分页、搜索、关联删除及重启持久化。`node frontend/tests/discussion.cjs` 使用真实接口验证发帖、回复、教材选择、公式预览、脚本清理、草稿和桌面/手机布局。两项已加入现有 CI。
