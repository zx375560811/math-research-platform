# 公理数学客户端（Windows 单机版）

这是“云数学系统”的单机客户端：文献、阅读进度、高亮和笔记都保存在本机，不需要服务器、不需要登录、不需要联网（AI 对话除外）。

## 安装

1. 把整个压缩包解压到一个**有写入权限**的目录，例如 `D:\Axiom`；
   **不要**放在 `C:\Program Files` 下。
2. 双击 `start.bat`。
3. 等待浏览器自动打开 `http://127.0.0.1:18080/`。首次启动会在当前目录创建 `data`。

## 使用

- **导入教材**：点左下角“管理平台” → 文献库 → 导入文献；支持 PDF / DJVU。
- **阅读**：在工作台进入“文档库”或“数学与应用数学”，打开教材即可。
- **进度/高亮/笔记**：自动保存在本机 `data` 目录。
- **AI 对话**：先在“管理平台 → API 设置”填写第三方 OpenAI 兼容接口：
  - 基础地址：例如 `https://api.deepseek.com/v1`
  - 模型：例如 `deepseek-chat`
  - API Key：你自己的密钥
  - 勾选“启用”并保存
  然后回到阅读器，在右侧 AI 面板选择“管理员默认 API”提问。

## 停止与备份

- 停止：双击 `stop.bat`，或关闭任务栏里的 Axiom 窗口。
- 备份：关闭客户端后，复制整个 `data` 文件夹。
- 换电脑：把整个客户端目录和 `data` 一起复制过去。

## 更新

用新版覆盖 `app`、`frontend`、`runtime` 三个目录，**保留 `data`**。

## 常见问题

- 浏览器没有自动打开：手动访问 `http://127.0.0.1:18080/`。
- 启动失败：查看 `logs\server.log`；常见原因是端口 18080 被占用，或杀毒软件拦截了 `runtime\bin\java.exe`。
- 端口被占用：关闭占用 18080 的程序后再启动；不要同时开两个客户端。
- AI 报错：检查 API 地址、模型名、密钥和账户余额；本客户端只负责转发请求。
- 扫描版 PDF 没有文字层：不能选段高亮，这是文件本身限制，不是客户端故障。

## 目录说明

```text
Axiom-Desktop/
├─ start.bat          启动
├─ stop.bat           停止
├─ run-server.bat     实际启动脚本（由 start.bat 调用）
├─ app/               Java 服务
├─ frontend/          页面、PDF.js、DjVu、公式渲染
├─ runtime/           内置 Java 17 运行时
├─ data/              本地数据库、PDF、笔记（备份这个目录）
└─ logs/              运行日志
```
